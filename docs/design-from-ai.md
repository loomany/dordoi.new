# Dordoi.help — контекст для AI design generation

## Что это

**Dordoi.help** — digital SaaS вокруг рынка **Дордой** (Кыргызстан). Это **не** классический маркетплейс в духе Wildberries, Ozon или AliExpress.

Платформа объединяет:

- **Покупателей** — опт из СНГ, заявки, каталоги, экономия времени на поездках по рынку.
- **Поставщиков** — продавцы Дордоя: витрина, лиды, цифровое присутствие.
- **Байеров** — посредники: подбор, проверка качества, сборка заказов, логистика как услуга.

## Позиционирование

- **B2B + сервисная экосистема** вокруг опта и регионального снабжения.
- **Чистый SaaS**: ясная иерархия, премиальный лендинг, без «шумного» marketplace UI.
- **Цель лендинга**: объяснить роли, ценность для каждой стороны и привести к CTA «Начать бесплатно» / переход в каталог.

## Ограничения для генерации `landing-spec.json`

- Секции приложения ожидают ids: `valueProps`, `audiences`, `howItWorks`, `ecosystem`, `ctaBand`.
- Hero: `layout: "split"`, `mockupPosition` `left` | `right`, `ctaOrder` — перестановка трёх CTA: `buyer`, `supplier`, `buyerAgent`.
- `messageKeys` в spec должны указывать на существующие ключи в `messages/ru.json` под `Pages.home.hero.*`.
- Типографика и spacing — только токены вида `d-text-*`, `d-space-*`, `d-block-gap` (см. `styles/tokens.css` и текущий `docs/landing-spec.json`).

При обновлении spec после генерации — прогнать `npm run build` и визуально сверить главную.
