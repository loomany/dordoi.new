# i18n и переводы

## Файлы

- `messages/ru.json` — **source of truth** по ключам и русскоязычному тексту.
- `messages/kk.json`, `kg.json`, `uz.json`, `tj.json` — **оверлеи**: достаточно перечислить только отличающиеся от RU ветки; при рантайме выполняется merge с RU (`i18n/request.ts`).
- Пустая строка в оверлее **не** перекрывает RU (остаётся русский текст).

## Проверка ключей

```bash
npm run check:i18n
```

Скрипт падает с ошибкой, если в оверлее есть «осиротевшие» листья — путь ключа отсутствует в `ru.json`.

## Автоперевод (offline)

```bash
npm run translate:messages -- --locale=kk
```

Требуется `OPENAI_API_KEY` и `OPENAI_TRANSLATION_MODEL` (по умолчанию `gpt-4o-mini`). Скрипт находит листья, которые есть в `ru.json`, но **отсутствуют** в целевом JSON, и дописывает переводы в файл локали.

## SEO и UI

Все пользовательские строки (включая `aria-label`, навигацию, SEO title/description, H1/H2 на страницах) лежат в `messages`. Компоненты не содержат user-facing литералов.
