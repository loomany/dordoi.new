## Title / H1 / metadata changes

- **Title (layout adds `| Dordoi.help`):** `Поставщик {category} на рынке Дордой` or fallback `Поставщик рынка Дордой`
- **H1:** same safe category-based string
- **Meta description:** safe copy with «Контакт доступен через сервис Dordoi.help» — no phone/social
- **Breadcrumb leaf:** `Поставщик` (not store name)
- **Visible sidebar label (mobile):** `Поставщик {category}` or `Поставщик №{number}` from UUID tail
- **DB `store_name`:** unchanged; catalog cards may still show store title on cards (UX tradeoff documented)

## Vendor robots / index policy

```typescript

vendorProfileRobotsPolicy(slug) // safe → index,follow; legacy → noindex,follow
```

Smoke (legacy slugs): **`noindex, follow`** on `asso-corsets`, `arusha-kg`, `slavyana-moda`.  
Category pages: **`index, follow`** unchanged.
